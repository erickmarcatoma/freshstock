CSV Upload Requirements

FreshStock processes standard CSV files locally in your browser. Ensure your file includes the required headers listed below.

📋 Required & Optional CSV Headers +

Your CSV file should include a header row with the following column names (case-insensitive):

Header Name Status Description & Example
Product Name Required Name or description of the item (e.g., Whole Milk 1 Gal)
Expiration Date Required Date formatted as YYYY-MM-DD or MM/DD/YYYY
Quantity in Stock Required Current stock count on hand (e.g., 25)
Minimum Stock Threshold Required Reorder alert threshold count (e.g., 10)
Brand Optional Prepended to item name if not already included
Quantity Sold Optional Used to calculate daily usage velocity for DOI forecasting
Example CSV Format: 
Product Name,Expiration Date,Quantity in Stock,Minimum Stock Threshold
Valley Whole Milk 1 Gal,2026-08-15,45,15
Hills Farm Greek Yogurt,2026-08-05,8,20
